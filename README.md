# MLP Versicherungen — MoneyMoney-Erweiterung

MLP-Versicherungsverträge (Kundenportal) in MoneyMoney.

Version: **0.92** (Beta)
Repository: https://github.com/rosch100/MLP-Versicherungen-MoneyMoney
Gemeinsame Infos: https://github.com/rosch100/moneymoney-extensions

Das ist nicht das FinTS-Giro der MLP Bank, sondern nur die Versicherungsverträge
im Kundenportal.

## Installation

Unsignierte Datei:
[MLP Versicherungen.lua](https://raw.githubusercontent.com/rosch100/MLP-Versicherungen-MoneyMoney/main/MLP%20Versicherungen.lua)

Datei nach
`~/Library/Containers/com.moneymoney-app.retail/Data/Library/Application Support/MoneyMoney/Extensions`
kopieren, oder im Klon `./link_ext.sh` ausführen.

Unsignierte Plugins: MoneyMoney-**Beta**, Signaturprüfung unter
*MoneyMoney → Einstellungen → Erweiterungen* ausschalten.

## Einrichten

*Konto hinzufügen* → *Andere* → **MLP Versicherungen**.

Anmeldung mit Benutzername/Passwort oder per Cookie-Import (`COOKIE:…` im
Passwortfeld). Cookie-Ablauf:
[Hub — Cookie-Import](https://github.com/rosch100/moneymoney-extensions#cookie-import-beta-extensions).

## Nutzung

Nach dem Einrichten den Zugang aktualisieren. Bei Cookie-Anmeldung Session bei
Bedarf erneuern.
